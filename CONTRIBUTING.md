# Contributing

Use Node.js 24 and run `npm run check` before proposing a change. The project
has no third-party dependencies; keep additions small and explain why they help.
Include regression tests for behavior changes. Never commit credentials or
personal data, and do not include third-party media or puzzle inputs without
redistribution rights. For Canvas changes, also check the page in a real browser
at desktop and phone widths, with the theme button operated by keyboard.

Report vulnerabilities privately as described in SECURITY.md.
